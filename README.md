# Delta SMS Forwarder — 0.2.0
نسخه مستقل اندروید برای ارسال نمونه‌های ساختگی و اعلان‌های ثابت سفارش که کاربر دستی انتخاب و تایید می‌کند. هیچ مجوز READ_SMS یا RECEIVE_SMS و هیچ دسترسی به اعلان سایر برنامه‌ها ندارد. پکیج مستقل ir.delta.smsforwarder.

## Build
GitHub Actions → Build Delta SMS Forwarder demo → Artifacts → Delta-SMS-Forwarder-demo-APK. Extract app-debug.apk.
JDK 17, Android SDK 35, Gradle 8.9. Local: gradle :app:testDebugUnitTest :app:assembleDebug.

## Test
ربات آزمایشی خود را با /start فعال کنید. توکن و Chat ID را فقط در گوشی وارد کنید. ارسال نمونه را فعال کرده و تست اتصال را بزنید. توکن در Android Keystore رمزگذاری می‌شود. برای تست صف، اینترنت را قطع کنید و یک نمونه بفرستید.
این نسخه debug است. آزمون روی گوشی انجام نشده. در صورت قطع ارتباط پس از پذیرش درخواست، تلاش مجدد ممکن است پیام نمونه را تکرار کند. تاریخچه محلی پیام‌های تلگرام را حذف نمی‌کند.

## اعلان واقعی انتخابی
در برنامه پیامک، یک پیام را دستی Share کنید و Delta SMS Forwarder را انتخاب کنید. متن فقط محلی نمایش داده می‌شود. تنها عبارت‌های دقیق آماده‌سازی، ارسال، تحویل یا لغو سفارش پذیرفته می‌شوند؛ پس از تایید فقط متن ثابت همان دسته، شناسه و زمان تایید ارسال می‌شود. پیام‌های دیگر از جمله رمز و کد ورود، یا متن دارای اطلاعات اضافه، رد می‌شوند. شماره فرستنده و زمان اصلی پیامک از Share استاندارد قابل استخراج نیست. هیچ متن خامی به صف ارسال یا تاریخچه وارد نمی‌شود.
APK آزمایشی با کلید debug محیط CI امضا می‌شود؛ ممکن است برای نصب روی نسخه قبلی لازم باشد نسخه قبلی را حذف کنید (تنظیمات محلی حذف می‌شود).
